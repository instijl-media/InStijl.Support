[InStijl.AI](http://InStijl.AI) consists of a collection of so-called "AI Tools". Each tool has its own specialty, such as writing copy, generating images, writing blog posts, building internal links, SEO optimization, etc.

In the sidebar menu on the left, you can find the different groups in which the AI Tools are organised. Select one of these menu-items to see which tools are available for this type.

Many of the tools can also be used in the **Automation** tool. Here you can automatically run the different AI-tools!

Are you missing a specific tool or functionality? Please [contact us](https://www.instijl.support/nl/apps/instijl-ai/feedback-and-bugs), and who knows, this feature might be included in our next update!

> **Tip**: Use the shortcut Ctrl+K within the [InStijl.AI](http://InStijl.AI) app or click on "Search AI tools" at the top. Then type in what you want to do, for example *"SEO optimization", "Add FAQ schema", "Build internal links".* You will then receive one or more recommendations for Tools that can help you with this.
